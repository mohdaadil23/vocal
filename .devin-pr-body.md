# feat: MVP vocal separation app (FastAPI backend + React frontend)

This PR implements a minimal, deployable MVP that removes vocals from songs.

- Frontend: Vite + React single page with drag-and-drop/click-to-upload, progress indicator, and results view with two audio players (Instrumental + Vocals) and download buttons.
- Backend: FastAPI API that accepts audio uploads, runs Demucs (two-stem) to split into vocals and accompaniment, renames accompaniment to instrumental, and serves the result files under `/files`.

Screenshot (local dev):
![Vocal Splitter UI](/home/ubuntu/screenshots/localhost_5173_111725.png)

Run locally:
1) Prereqs
   - Python 3.12+, Node 18+, ffmpeg installed
   - Ubuntu: `sudo apt-get update && sudo apt-get install -y ffmpeg`

2) Backend
   - `python -m venv .venv && source .venv/bin/activate`
   - `pip install -U pip && pip install -r backend/requirements.txt`
   - `uvicorn app.main:app --reload --port 8000 --app-dir backend`
   - Health: http://localhost:8000/api/health

3) Frontend
   - `cd frontend && npm install && npm run dev`
   - Open http://localhost:5173

Usage:
- Drag-and-drop or click to upload an audio file (mp3, wav, flac, m4a, ogg).
- Spinner shows while processing.
- On completion, you can play and download vocals and instrumental.

Notes:
- First run downloads Demucs model weights; may take a few minutes.
- Outputs are stored in `backend/storage/{job_id}` and served from `/files/{job_id}/...`.
- Temporary uploads are cleaned per job.
- CPU-only; performance depends on machine. For quick testing, use short clips.

Implementation details:
- Endpoint: POST `/api/separate` -> returns `{ job_id, vocals_url, instrumental_url }`
- Static serving: `/files` mounts `backend/storage`
- CORS: enabled for local dev
- Robust stem detection: supports both `accompaniment.wav` and `no_vocals.wav` naming variants from Demucs two-stems.
